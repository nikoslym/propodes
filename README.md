# Πρόποδες

Showcase site for Propodes, an organic extra virgin olive oil from Lakonia. Greek is the default language. English lives under `/en`.

```bash
npm install
npm run dev
```

Orders go through the contact form and the two phone numbers. There is no shop and no prices.

Mail is sent with [Resend](https://resend.com) when `RESEND_API_KEY` and `ORDER_FROM_EMAIL` are set. See `.env.example`. Until then the form asks people to call or email.

Display type is Ubuntu for now. N27, used on the English label, is not in the repo yet.
